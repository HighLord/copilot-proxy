Attachments

  
To have Copilot read a file, upload it with POST /v1/files?filename=name.pdf (raw bytes in the body), then pass the returned id back in the attachments array of a chat request, e.g. {"attachments":[{"id":"SPO_…","name":"name.pdf","url":"https://…"}]}. Files go to the "Microsoft Copilot Chat Files" library.
